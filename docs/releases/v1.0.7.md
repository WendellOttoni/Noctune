# Noctune v1.0.7

Stability, security and usability update.

- Preserve queue identity across library rescans and paused state during seeks.
- Accumulate rapid seek requests and trim decoder preroll accurately.
- Verify credential persistence and preserve legacy credentials when migration fails.
- Bound playback/prefetch workers, cancel obsolete work and limit subprocess lifetime.
- Add bounded disk-backed audio caching, expiry and protection for active files.
- Support current Spotify playlist response contracts and report service failures explicitly.
- Add setup, privacy-safe diagnostics and a shared help/command catalog.
- Add core EN/PT-BR UI strings, simple symbols and small-terminal safeguards.
- Lock dependencies/toolchain and verify release downloads with SHA-256 and recoverable replacement.

Validation: 77 automated tests passed locally on Windows. Native credential stores,
authenticated integrations and physical audio still require platform-specific smoke tests.
Spotify playback remains remote control through Connect, not an embedded audio engine.
Some integration messages remain untranslated.

Downloads include SHA-256 sidecars and build manifests. Checksums protect integrity;
the updater does not verify the separately generated build attestations.
