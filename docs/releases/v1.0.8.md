# Noctune v1.0.8

Complete English and Brazilian Portuguese interface support.

- Localize library and queue panels, radio, lyrics, audio controls, track details,
  playlists, profiles, sharing, and integration notifications.
- Localize terminal help, setup prompts, diagnostics, and exported shortcuts.
- Update cached library headings when changing languages without restarting.
- Match stable command IDs in the command palette, so `:language` works in either language.
- Preserve original track, artist, album, station, and user-created names.

Open `Ctrl+P` and run `:language` to switch and save the language preference.
English remains the default. Technical error details from services/libraries and
logs retain their original text; configuration keys and JSON output remain stable.

Validation: compilation and formatting checks passed; all 80 automated tests
passed locally on Windows, including language configuration, formatted messages,
relative timestamps, and help rendering in both languages.
